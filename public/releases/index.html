リリースノート

サイトの機能追加・修正・セキュリティ対応の記録です。事案データの追加・更新は毎日行っているため、ここには載せていません（ニュースと GitHub の履歴をご覧ください）。

2026年10月21日セキュリティ

  • Node.js の2026年10月のセキュリティリリース（v26.12.1 / v24.22.1 / v22.23.4。TLS の証明書のホスト名確認のすり抜け、Brotli の範囲外書き込みなど10件）に対応しました。GitHub Actions のすべてのワークフローで check-latest: true を指定し、ビルドやニュース調査で常に最新の Node.js 26 を使うようにしました。
  • 公開しているサイトは静的な HTML と JSON だけで、公開サーバー上では Node.js は動いていません。Node.js が動くのは GitHub Actions のビルド・調査処理だけです。

2026年10月18日機能追加

  • ニュース（/news/）を追加しました。公表日ごとのカレンダー、委託先から広がった「話題の連鎖」、その日に公表された事案を見られます。日付ごとのページ（/news/YYYY-MM-DD/）と JSON（/news/index.json・/news/YYYY-MM-DD.json）もあります。
  • 利用規約（/terms/）を追加し、robots.txt に Crawl-delay と規約への案内を加えました。

2026年10月16日依存関係

  • js-yaml を 5.4.3 に更新しました。

2026年10月11日機能追加

  • ランキング・ビジュアライズの各セクションに個別ページ（例：/ranking/org/）とシェア画像を追加しました。
  • Issue に書かれた記事の URL から、AI が事案データの下書きや続報の更新 PR を作る仕組みを追加しました。
  • 共有された検索 URL（?q=）を開いたとき、読み込み中に検索欄と結果が空に見える問題を修正しました。

2026年10月9日機能追加

  • ビジュアライズに「漏洩の系譜」（家系図・リスト）を追加し、委託先から広がった事案をたどれるようにしました。複数の委託元・経由先を持つ事案にも対応しました。
  • ニュースの自動調査を2時間ごとにし、日経・日経クロステックを調査元に加えました。
  • GitHub Actions の実行環境を Ubuntu 26 に固定しました。

2026年10月8日機能追加セキュリティ

  • 事案ごとの個別ページ（/breach/事案ID/）と、事案ごとのシェア画像、sitemap.xml を追加しました。
  • 「お漏らし無し」（情報が漏れた形跡が確認されなかった事案）を追加し、集計から外して専用のランキングを作りました。
  • 「企業側が調査中」と「情報の信頼度」を分けて表示するようにしました。
  • 発生から公表までの日数を、ランキング・一覧・個別ページに追加しました。
  • 関連ページ（削除された導入事例のアーカイブなど）を表示できるようにしました。
  • GitHub Actions の権限を最小限にし、使うアクションをコミット SHA で固定しました。ニュース候補 Issue の乗っ取りや Markdown の埋め込みも防ぐようにしました。

2026年10月7日公開

  • サイトを公開しました。日本国内で情報漏洩を公表した企業・サービスの一覧です。
  • ランキング（企業・業界・原因・攻撃手法・委託先・脆弱性を悪用された箇所）と、ビジュアライズ（月ごとの推移・地域別マップ）を追加しました。
  • 漏洩した情報の重要度による色分け、ダークモード（ドット絵の「水漏れする部屋」）、最終更新日時の表示を追加しました。
