第5条 スクレイピング・自動取得について

本サイトは個人が運営しているため、サーバーに負荷をかけないよう、自動での取得は次のルールに従ってください。

  1. データを集める目的なら、HTML をスクレイピングせず、第4条の JSON か GitHub を使ってください。
  2. HTML のスクレイピングは、教育・研究・個人の学習（スクレイピングの練習など）の目的に限り認めます。その場合も、次を守ってください。

    • 取得した内容はキャッシュし、同じページを短い間隔で繰り返し取得しない（データの更新は1日に数回程度です）
    • User-Agent に、プログラム名や連絡先（GitHub のアカウントなど）を入れる
  3. 上記以外の目的での HTML の継続的・網羅的なスクレイピングは禁止します。
  4. JSON の取得も、短い間隔で繰り返さないでください（1日に数回程度で十分です）。
  5. robots.txt に従ってください。
  6. 運営者は、サーバーに過度な負荷をかけるアクセスを、予告なく制限・遮断することがあります。
